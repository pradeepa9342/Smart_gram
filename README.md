# 💎 SMART-GRAM: Smart Village Digital Management System

SMART-GRAM is a comprehensive, bilingual (English & Tamil) digital platform designed to bridge the digital divide in rural areas. It empowers villagers with real-time information and provides municipal officers with tools to manage village resources efficiently.

---

## 🌟 Key Features
*   🌾 **Agriculture (e-Mandate)**: Live market prices and seasonal crop suggestions.
*   💧 **Water Monitoring**: Real-time visualization of village water levels with low-level alerts.
*   🏥 **Healthcare Services**: Doctor availability status and local health drive notifications.
*   📜 **Government Schemes**: Searchable database of schemes for farmers, women, and seniors.
*   📝 **Citizen Complaints**: Digital grievance system with status tracking and admin responses.
*   🌍 **Bilingual Support**: Full English and Tamil language integration.

---

## 🚀 Quick Start

### 1. Prerequisites
Ensure you have **Node.js** (v18.x or later) installed on your system.

### 2. Launching the Project
Open your terminal in the project root directory and run:

```bash
# First, install dependencies (if not already installed)
npm install

# Then, start the development server
npm run dev
```

The application will be live at `http://localhost:3000`.

*Note: For Windows users encountering script execution errors, use:*
`Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass; npm run dev`
